Team journey · Lists · Reminders

A bar's closing checklist

At The Copper Tap, the closing list was a laminated sheet behind the register, and twice this year the back door was left unlocked. Rosa, the manager, moved the close onto a shared Portico checklist. Every bartender has it on their phone, a nightly reminder kicks off the close, and Rosa gets one more ping only if the back door isn't checked off.

  • You'll needPortico Mobile for each person, and an agent. A Cloud Agent is fine.
  • AppsPortico Lists (Checklist, Reminders, Notifications)
  • TimeAbout 20 minutes to set up

What you'll end up with

  • A "Closing" checklist the whole crew shares.
  • A nightly reminder to everyone on the list when it's time to start closing.
  • A safety-net reminder that pings only the manager, and only if the back door isn't checked off.
  • A notification each time a step is checked off, so the manager can follow along from home.

  1. Make the Closing checklist

    One list, in the order the close actually happens.

    1. In Portico Lists, tap + (New list).
    2. Name it Closing, set Type to Checklist, and tap Create.
    3. Add each step: Restock beer cooler, Wipe and sanitize taps, Run glass washer, Count drawer, Take out trash, Lock back door & set alarm.
    4. Turn on Manual reorder in the list's Settings if you need to change the order.

    First time? The grocery list journey covers installing Portico and getting an agent.

  2. Make it reusable every night

    Steps stay where they are when checked, so tomorrow's crew sees the same list.

    1. In the list's Settings, under When marking items, choose Mark in place.
    2. When the opener arrives, they tap Mark all undone to reset for the night.

  3. Add the nightly "start closing" reminder

    A list reminder goes to everyone on the list at the same time every night.

    1. In Settings, go to Reminders and tap Add list reminder.
    2. When: tonight at 1:30 AM. Repeat: Every day.
    3. Notify: Everyone on this list.
    4. Note: Last call was 1:00. Start the close. Tap Add.

  4. Add a safety net on the back door

    A reminder on a single step that only the manager gets, and only if the step isn't done.

    1. Tap the bell on Lock back door & set alarm (Add reminder).
    2. When: 2:15 AM. Repeat: Every day.
    3. Notify: Just me.
    4. Note: Back door not checked off yet. Tap Add.

    Why Rosa sleeps: a repeating reminder pauses while its step is checked. If the crew checks off the back door before 2:15, she gets nothing. If they don't, her phone buzzes.

  5. Invite the crew

    Each bartender joins the list once, from their own phone.

    1. Tap the Users pill, then + (Invite someone).
    2. Invite name: the person's name. Access rights: User for bartenders, Admin for a shift lead who can edit the list.
    3. Tap QR at the start of their shift. They scan it with their Camera and tap Accept in Portico Mobile.
    4. Have each person turn on Allow notifications in Lists Settings → Notifications.

    Someone leaves? Remove them from the list's Users panel. Nobody needs to change a shared password.

  6. Watch the close from home

    The manager can follow along without calling the bar, and the crew can see who's done what.

    1. In the list's Settings, under Notifications, turn on Item checked off.
    2. Each time someone checks a step, everyone else on the list gets a notification titled Closing, for example Kim checked off Count drawer.
    3. This setting covers the whole list. Anyone who wants quiet nights off can turn off notifications for Lists on their own phone.
