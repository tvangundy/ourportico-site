Family journey · Lists · AI Chat

What the house remembers, and what stays yours

The Lindstroms wanted one assistant for meal planning and homework, without every fact becoming household knowledge. Portico AI keeps a short fact in one of three places. A personal note rides along only when that person asks. A conversation note stays in that thread. A household note is in every reply, and only the host can save it.

  • You'll needPortico Mobile, an agent, and an API key saved on that agent. A Cloud Agent is fine.
  • AppsPortico Lists (AI Chat, Conversation)
  • TimeAbout 15 minutes after AI is set up

What you'll end up with

  • A private AI Chat that remembers one person’s allergy, and leaves it out of everyone else’s questions.
  • A family thread that remembers “vegetarian through October” for anyone in that conversation.
  • One household fact, “the dog is Biscuit,” included in every Portico AI reply on the agent.

  1. Open a private AI Chat

    A one-person thread is where a personal fact belongs. The model replies after every message you send.

    1. In Portico Lists, tap + (New list).
    2. Name it Maya, set Type to AI Chat, and tap Create.
    3. If AI Chat is missing from the type list, save an API key in the agent console under AI first.

    New to Portico? The grocery list journey covers installing the app and getting an agent. Setting up the key is in the AI guide.

  2. Save a fact that is only yours

    User memory is included only when you are the person who asked. A sibling’s question does not pull it in.

    1. In the Maya chat, send Remember that I’m allergic to shellfish.
    2. Portico AI proposes the fact. It is not saved yet.
    3. Tap Save memory on Save this user memory.
    4. Ask What should I skip at the oyster bar? The reply can use the allergy. The same question from someone else’s chat cannot.

    Why confirm: the model may suggest a fact. The row is written only after a person saves it. Dismiss it and nothing is kept.

  3. Save a fact for one conversation

    List memory belongs to the thread. Anyone posting there gets it. A different chat does not.

    1. Create a Conversation named Meals and invite the people who plan dinner.
    2. In that list’s settings, turn on Portico AI is in this conversation.
    3. Send Remember that we are vegetarian through October.
    4. Tap Save memory on the confirm card.

    Why it is not a household rule: October is a plan for this thread. A private homework chat should not inherit it, and it should not follow every person into their own AI Chat.

  4. Save a fact for the whole house

    Agent memory is included in every Portico AI reply on this agent. Only the host can save or delete it.

    1. From the host’s phone, in any AI Chat, send Remember for the whole house that the dog is Biscuit.
    2. Tap Save memory on the confirm card.
    3. Ask from the Meals thread, and from Maya’s private chat, What is the dog’s name? Both replies can use it.

    Why the host is the only one: an invitee can use the assistant on lists you shared. They cannot rewrite what every reply on the agent knows. If you later point AI at a different model, Biscuit, the allergy, and the October plan stay on the agent.
